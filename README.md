# Padaria Database Project

## How to run
```
git clone
cd padaria-database
sqlite3 padaria.db < scripts/create2.sql
sqlite3 padaria.db < scripts/populate2.sql
```

After that, you should have a `padaria.db` file in the root directory of the project with some data in it.
